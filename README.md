# 전세한눈 · jeonsehannun

가계약금부터 보증금 반환까지, 집별 확인 근거와 다음 행동을 관리하는 정적 웹앱입니다.

## v0.1 구현

| 기능 | 구현 상태 |
|---|---|
| 후보 주택 생성·수정·비교 | 구현 |
| 6단계 점검, 근거 메모·서류 연결 | 구현 |
| 원본 PDF·이미지·TXT 보관·열람 | 구현 (IndexedDB) |
| 재접속 시 저장 상태 복원 | 같은 브라우저·출처에서 구현 |
| 변경 이력·시점별 입력 비교 | 구현, 등기 자동 비교 아님 |
| 기록·원본 포함 백업 및 새 프로젝트 복원 | 구현. 복원 시 서류 연결·활동 이력·스냅샷은 원본 백업을 별도 참고 |
| 반환보증 진행 상태 | 사용자 입력. 기관 실시간 연계 아님 |
| 로그인·서버 동기화·AI/OCR·공공 API | 미구현 |

## 실행

Node.js 22+, Python 3 사용.
```
npm install
npm run check
npm test
npm start
```
개발 서버: http://localhost:4173
브라우저 테스트: `npx playwright install --with-deps chromium && npm run e2e`.
`jeonsehannun` 이름으로 복제한 폴더에서 실행합니다.
